越权是怎么被拦住的

  1. 接口级：AuthInterceptor 读 session 里的登录用户，方法上没有对应权限码直接返回 403，请求进不到 Service。
  2. 数据级：部门管理员查询时强制把 deptId 换成本部门；显式传别的部门 → 403（见 UserService.applyScope）。
  3. 角色级：非管理员只能维护 / 分配 level 比自己大的角色，不能动同级或更高级的账号（见 checkTargetMutable、checkRoleAssignable）。
  4. 调岗（改角色）单独一个权限点 role:write，只有系统管理员有。
